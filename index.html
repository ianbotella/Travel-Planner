Acceso para guardar cambios

Para que los datos que cargues en cada reserva se guarden en el repo (y se vean desde cualquier dispositivo), necesitás un Personal Access Token de GitHub con permiso de escritura sobre este repo.

  1. Andá a github.com/settings/personal-access-tokens/new.
  2. Elegí "Only select repositories" → Travel-Planner.
  3. En "Repository permissions" → Contents: Read and write.
  4. Generá el token y pegalo acá abajo.

El token se guarda solo en este navegador (localStorage) y se usa únicamente para hablar directo con la API de GitHub — nunca se envía a ningún otro lado.
